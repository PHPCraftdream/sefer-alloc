**F1 — crate-doc всё ещё называет `extras` «an arbitrary sorted list» — ровно та формулировка, которую собственный README крейта документирует как исправленную task #731 за занижение контракта `Params::extras`.**
Где: `crates/size-classes/src/lib.rs:16` (крейт-уровневый rustdoc, первый абзац docs.rs-страницы): «a `const fn` sorted-merge of a geometric progression … with **an arbitrary sorted list of explicit `extras`**». Реальный контракт (задокументирован на `Params::extras`, `lib.rs:80–90`, и в `# Panics` `build_table`): список **строго возрастающий**, каждый элемент **кратен `min_block`** и **`>= min_block`** — не «arbitrary» и не просто «sorted» (sorted допускает дубликаты; строгая монотонность — нет).
Почему это не вкусовщина: README этого же крейта (:12–16) несёт явную пометку «task #731 corrected this line, which previously said "an arbitrary sorted list," understating the `Params::extras` contract» — то есть проект сам уже адъюдицировал эту фразу как занижающую контракт и исправил её в README («a strictly increasing list of `min_block`-multiple, `>= min_block` explicit extra classes»). Крейт-док при экстракции (`121d657`) получил неисправленный вариант и пронёс его через все семь циклов. Проверено `git log -S 'arbitrary sorted list'`: фразу вносил только `121d657`; `5ffb85c` (hygiene run 3) правил её вхождение только в README. Grep по «arbitrary» во всех отчётах кампании — ноль упоминаний: находка новая.
Вес — P4, не P3: в отличие от run-6 F1 (опровергнутое фактическое утверждение о семантике компилятора на публичном rustdoc) здесь занижение machine-checked-precondition, нарушение которого паникует громко и с именованной диагностикой прямо в const-eval потребителя — введённый в заблуждение читатель получает мгновенную самообъясняющую ошибку, а не тихое неверное поведение; авторитетный контракт корректно изложен в этом же файле ~65 строками ниже. Направление ошибки — «обещает больше свободы, чем есть», без silent-hazard.
Фикс — замена полуфразы по образцу README: «with a strictly increasing list of `min_block`-multiple (`>= min_block`) explicit `extras`».
