# B4 A3: межклассовый перенос блоков (PMU-пробник), только измерение

> Измерительная ветка `b4-pmu`@32eed166 (origin); скрипты прогона
> (`docs/perf/b4_pmu/pmu_*.sh`, `pmu_per_op.mjs`) живут там. В main скопированы
> сырьё `docs/perf/b4_pmu/_raw_*.txt` и пробник `examples/b4_pmu_probe.rs`
> ([[example]], required-features `production`).

## Почему

Ядра churn16/churn64 судьи J1′ делят одно кольцо слотов (CHURN_SLOTS): часть
блоков churn64 выделяется на местах, освобождённых churn16, т.е. судья частично
измеряет МЕЖКЛАССОВЫЙ перенос блока (магазин → сброс → пополнение → выдача),
а не только собственно одноразмерный churn. Пробник разделяет эти два режима:
один размер против смешанного 16/64 на том же кольце.

## Метод

`examples/b4_pmu_probe.rs` (ветка `b4-pmu`): кольцо `live` слотов, операция —
free случайного слота + alloc замены, rdtsc-тайминг порций ABBA/BAAB
(A = sefer, B = mimalloc); режим `inter` с аргументом `size2` гоняет два размера
по ОДНОМУ кольцу (смешанный режим). Сырьё: `docs/perf/b4_pmu/_raw_windows_*.txt`
(тики/оп), `_raw_linux_perf_stat.txt` (perf stat). Вывод ниже — дословный вывод
`scripts/b4_pmu_summary.mjs` (медианы по сценариям с assert'ами):

```text
# B4 A3 cross-class transfer — medians from docs/perf/b4_pmu/_raw_*.txt (generated by scripts/b4_pmu_summary.mjs)
# scenario rows: single-class n=4, mixed-16/64-portion128 n=3, perf_stat lives=1,64,256,4096

| Scenario | sefer ticks/op (median) | mimalloc ticks/op (median) |
|---|---:|---:|
| single-class churn L=256, size=16, portion=128 (4 rows) | 21.005 | 39.764 |
| mixed 16/64 over ONE ring, portion=128, pollute=0 (3 rows) | 33.787 | 18.111 |

| sefer perf stat IPC (instructions:u / cycles:u, live sweeps) | IPC |
|---|---:|
| live=1 | 4.45 |
| live=64 | 4.56 |
| live=256 | 4.70 |
| live=4096 | 4.74 |
```

## Что это значит

- Одноклассовый churn L=256: sefer 21–22 тика/op, mimalloc 39–40 — sefer
  быстрее примерно вдвое (ИЗМЕРЕНО, медианы выше).
- Смешанный режим (16/64 порции по 128 на одном кольце): картина
  переворачивается — sefer 33–38 тика/op, mimalloc 18–20: каждый перенесённый
  блок у sefer проходит магазин → сброс в список → пополнение → выдачу.
- perf stat: IPC sefer ≈ 4.7 на одном классе (live=256/4096) — время не в
  кэш-промахах; на смешанном режиме ~1/3 времени sefer —
  `try_drain_freelist_batch` + `flush_class_internal` (perf annotate, сырьё
  `_raw_linux_live_sweep.txt` / `pmu_ann.sh` на ветке `b4-pmu`; ОЦЕНКА по
  annotate-выводу).
- Вердикт для судьи (A3): отставание sefer на churn в судье J1′ v1 —
  межклассовый перенос, а не цена одноразмерного churn; депо-прототип B1-D
  (карточка 117) — кандидат-ответ.
