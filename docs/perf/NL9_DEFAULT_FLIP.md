## 1. Question

NL-9 drops `misuse-checks` from `production`. The feature gates every check that only rejects a contract
violation (state byte, payload-start and bump bounds, flush and reclaim guards, realloc and Large-free address
checks, foreign realloc payload and commit-frontier checks). What does the flip cost or save on the real bundle?

## 4. Reading

- Instructions fall in every cell: -14.39 % on bulk 16 B, -14.39 % on bulk 64 B (equal to two decimals),
  -7.12 % / -6.83 % on larson T=1 / T=4, -9.67 % / -8.85 % on mstress T=1 / T=4
  (denominators: the `on` callgrind totals in the table).
- Time where the sample ranges do not overlap: see the last column; a cell marked "no claim" is not a time result.
- RSS: see the second table; the flip removes code and one metadata byte read per free, it adds no allocation.
- Not shown: the cold paths (the checks are absent there too, nothing is added).

## 5. Verdict

`perf(runtime)`: `production` no longer includes `misuse-checks`. A program that violates the `GlobalAlloc`
contract (double free, foreign or interior pointer, wrong layout) has undefined behaviour in `production`, as the
contract allows; `hardened` and `misuse-checks` keep the checks, and a debug build keeps them and aborts on a hit.
