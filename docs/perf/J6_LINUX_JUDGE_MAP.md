## 1. Question

J5 found mimalloc ahead in 6 of 7 judge scenarios on Windows. Is the gap specific to the Windows memory interface (VirtualAlloc, commit, decommit),
or does it show on Linux too, where `perf` and callgrind can attribute it?

- Same judge, same campaign as J5 (`examples/g1_wild_judge.rs`, scale 1, seed 1, 12 blocks, 3 repeats, the shuffle seed and arm alternation of `docs/perf/wg1/run.mjs`);
  the Linux binary is started through `wsl.exe -e` by `docs/perf/j6/run.mjs`; ns/op is measured inside the judge, so the launcher is outside every sample.
- Source identity: main `875ddcd6f6b3fe48bc4283cd4c7db915416cb985`, git-archive tar sha256 `31b1c4516f7df8b5bc5bad503da39b6c3b1f68d67dc79a118b36ee89bbd64e96`, judge binary sha256 `9b08a2410173a7cdc507236e5f41f83809c3e51506e875ce3040d7df2c2e8769` (`docs/perf/j6/ident.txt`, `docs/perf/j6/build.sh`).
