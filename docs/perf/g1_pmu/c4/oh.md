## 1. Нужен ли редизайн free

Быстрый путь free — нет: средних рычагов не осталось (B4_MATH_HACKS §6,
абляции ≤ 2 % на шаг, H1+H3, N1-free, K2). ОЦЕНКА пола при правилах владельца
≈ 40–45 Ir против 21–25: потолок pair16 t_mi/t_sefer ≈ 0.9–0.95; паритет на
pair16/churn16 при текущих защитах, вероятно, недостижим.

Перенос магазин ↔ сегмент — да, единственный крупный рычаг (−92 Ir/пару на
bulk16k). Сначала замерить потолок «перенос = 0» (P0).

ОЦЕНКА P0: bulk16k ≈ 172 Ir/пару (−34 % Ir), t_mi/t_sefer 0.511 → ~0.77
(0.70–0.85); остальные 10 ядер — 0.

## 2. Направления

- (a) массив смещений в метаданных: тела не пишутся, но ёмкость до
  SEGMENT/block_size записей на (сегмент, класс) — до 25 % payload для 16 Б;
  проигрывает (d).
- (b) локальный список страницы как у mimalloc: `mi_free` пишет `next` в тело
  освобождаемого блока — запрет R1-01; с магазином впереди вырождается в
  текущую схему. Не рекомендует.
- (c) больший склад: механизм подтверждён K5; RSS — ≥ 1 MiB блоков класса 64
  + 128 КиБ указателей, нужен decay; подогнан под живой набор судьи. Для
  отгрузки — решение владельца; как замер потолка — идеален.
- (d) байт состояния как неявное множество свободных блоков: при полном
  складе — FREE в байт + бит сводки + `sub_live` (метаданные, R1-01 соблюдён);
  refill — скан байтов по сводке. Убирает доверие к `next` из памяти
  пользователя. ОЦЕНКА bulk16k → ~0.70–0.72; churn/larson +0–3 %, pair 0.

## 3. P0 и контроль

- P0: в `depot.rs` для класса 3 (64 Б) K = 1024 отдельным массивом, счётчик
  `parked` шире u8; остальные классы как сейчас.
- Оракул: на bulk16k self Ir `flush_class_internal` + `try_drain_freelist_batch`
  ≈ 0; пик парковки ≈ 1015.
- Контроль: pair16/pair64 (`free_magazine_full` не вызывается), bulk64/churn64
  (парковка класса 64 работает, ≤ 8 магазинов).
- Правило решения: bulk16k ≤ −20 % при верхней границе CI < 0 → строить (d);
  меньше 10 % → переносную ветку закрыть.
- Риски P0: выход потока сбрасывает до 1024 магазинов; удержание сегментов;
  правила P12 (`depot/flush-reloads-parked`); Kani-харнесс с большим `Depot`.
