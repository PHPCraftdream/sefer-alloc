## 1. Question

`SidecarBitmap::publish` returns false for a granule whose class code was never issued (`classes.encoded(granule) == 0`): it drops a
cross-thread free of an address the allocator never handed out. Safe code cannot produce one; it costs one Acquire load of the class-map
leaf, a line the owner writes on issue, on every cross-thread free. What does it cost on the shipping default?

- Entry point: the real `SeferAlloc` `#[global_allocator]` — `docs/perf/nl11/xfree_probe.rs` (4096 cross-thread frees by one scoped

  examples, `--features production`, release, the repository's alignment RUSTFLAGS.

- Instructions: callgrind (MT: 100000 steps). Time: 5 repetitions of the order base, proto, proto, base (ABBA), 10 samples per arm and
