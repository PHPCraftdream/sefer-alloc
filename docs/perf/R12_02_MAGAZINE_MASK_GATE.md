# R12-02 — `clear_magazine_on_issue`: segment-base mask instead of a table lookup

**Class (R30-12):** `perf(runtime)` — the always-on `production` magazine-hit path changed
(`src/registry/heap_core/alloc/hot.rs`); the change also removes the only `expect` (a panic
point) from the `GlobalAlloc::alloc` hit path. Measured on the deterministic axis only
(callgrind `Ir` + estimated cycles); **no wall-clock claim** — wall-clock on this host
(WSL2) is noise.

Source: `docs/reviews/2026-10-06-063308-src-review-fxx-round-12.md`, card fxx R12-02 and §3 O-1.

## 1. The change

`HeapCore::clear_magazine_on_issue` cleared the magazine-residency bit of a block that is
leaving the magazine. It derived the segment base with
`self.core.canonical_root_for(issued).expect("issued magazine block belongs to a live segment")`
(Tier-1 `own_cache` compare, Tier-2 hash probe on a miss, and a panic path), while the bit is
SET through the cheap mask `os::segment_base_of_ptr` (`finish_magazine_refill`). It now uses
the mask and keeps the agreement with the table as a debug-only check:

```text
let base = os::segment_base_of_ptr(issued);
debug_assert_eq!(self.core.canonical_root_for(issued), Some(base), ..);
```

Why the mask is exact for every block that can sit in a magazine: Small/Primordial segments are
registered with `payload == base` and are `SEGMENT`-aligned; an offset canonical root exists
only for Large reservations with `align >= SEGMENT`, and Large blocks never enter a magazine.
The original R29-10 design (`benches/perf_gate_iai.rs`, "RAD-5 E4 block") was exactly this
mask; the table lookup was a later drift.

## 2. Entry point under test

`HeapCore` (`(*heap).alloc` / `dbg_clear_magazine_on_hit`, which calls the shared
`HeapCore::clear_magazine_on_issue` since task #2000). That is the layer where the changed
function lives and the one `SeferAlloc`'s `#[global_allocator]` path reaches on every magazine
hit; no `AllocCore`-level shortcut is measured.

Reading:

- The isolated per-hit cost of the clear step falls from 22.56 to 12.19 `Ir` (361/16 → 195/16);
  12.19 is exactly the figure `docs/perf/OPEN_ITEMS.md` item 17 measured for the original
  mask-based block, i.e. the change restores the documented baseline.
- End to end, `small_churn_16b` drops 630 `Ir` (−1.08 %, 630/58,201) and `small_churn_16b_2n`
  1,270 `Ir` (−1.95 %); estimated cycles move −0.62 % / −1.07 %. The largest layout-noise
  deviation in the control is 12 `Ir`, so all three end-to-end rows are well outside noise.

## 5. Path activation (R30-8)

`alloc_clear_magazine_only_16b` calls `HeapCore::dbg_clear_magazine_on_hit` 16 times per run,
which delegates to the same `clear_magazine_on_issue` the production hit path runs; the
per-hit delta above is therefore a direct measurement of the changed function, and the
`alloc_magazine_hit_only_16b` / `small_churn_16b` deltas are its end-to-end consequence.

## 6. Tests

- `tests/r12_02_magazine_hit_mask_equals_canonical_root.rs` — builds ≥ 24 live Small segments
  (so the 16-entry Tier-1 `own_cache` is oversubscribed), frees them, then drives repeated
  magazine hits (counted by the `alloc-stats` counter `tcache_hits`, so the test requires that
  feature and asserts at least 8 hits); in a debug build the new `debug_assert_eq!` checks
  mask == canonical root on every hit. Counterfactual: a mutant that offsets the mask by 16
  bytes makes the test panic at `hot.rs:48` with `assertion left == right failed: small
  magazine block must map to its segment base` (left `Some(0x1e264c00000)`, right
  `Some(0x1e264c00010)`); restored, the test passes.
- `tests/regression_r2_08_global_allocator_path_no_unwind.rs` — the existing no-unwind pin for
  the `GlobalAlloc` path still passes.

## 7. Caveats

- `Ir` and the callgrind cache model do not capture real cache or branch-predictor behaviour.
- The measured benches stay within `OWN_CACHE_SIZE` hot segments (Tier-1 hits). The case the
  review flagged — ≥ 16 simultaneously hot segments, where every Tier-1 probe misses and the
  old code paid the Tier-2 hash probe on each hit — is expected to save more; it is **not**
  measured here and no number is claimed for it.
