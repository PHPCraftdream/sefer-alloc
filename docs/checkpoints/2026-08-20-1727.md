## Decisions

- **Locks whose only stated reason is false get REMOVED, not kept as insurance** (#1241). The
  hedge "keep it in case the assert is strengthened" collapses when the state is thread-local:
  strengthening an assert does not let a thread see another thread's local.
- **`2f9d7b9` grandfathered as the FIRST false-positive exemption**, not the fifth grandfather
  (#1238). Teaching `hasNonCommentChange` to recognise string literals was rejected: the guard
  parses `--unified=0` hunks with no opening quote, so every failure mode of that reconstruction
  is a SILENT miss — the `09f4d16` defect passing green. A loud false FAILURE is the guard working.
- **The census total was DE-TYPED rather than corrected** (#1239). No principled difference could
  be articulated between that number and the one fifteen lines above that is deliberately not
  typed — and the inability to articulate it was taken as the answer.
- **`## X.Y.Z - Unreleased` for the three unpublished crates** (#1220), explicitly NOT unblocking
  publication. Stamping a date would reproduce Sol-F2, the exact defect the release guard exists
  to prevent. `numa-shim` got a real dated section because its 0.1.0 is genuinely live on
  crates.io (verified against the API, 2026-06-29).
- **The `Refused` seam routes the injected error THROUGH the real mapping arm** (#1219), not
  around it via an early return — so the test exercises the arm real callers reach, and the exact
  `PartialEq` payload assert catches an arm that drops or substitutes the error.
