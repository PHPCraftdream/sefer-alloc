## Decisions

- База нового кандидата — pinned f80, не D1′ и не непринятый B; актуальность remote main заново не проверена.
- Windows TLS access проверен как native lowering; registry binding/LUT/memo/cap tuning без нового evidence не переоткрывать.
- Новый механизм — завершённый magazine hit отдельно от продолжений с calls, не attribute permutation прежнего free helper.
- Первый gate — реально leaf native const16/64 wrappers, без entry push/sub-rsp/call на hit; если не получилось, закрыть эту форму без перебора attributes. Runtime wrapper не должен получить дополнительный frame tax.
