## Method notes worth keeping

- **Цитаты в собственных задачах перепроверять чтением файла.** Сверка нашла
  ошибку в моей же #1172: я ссылался на `lib.rs:55` как на предложение, которое
  надо править, а на `:55` стоит КОРРЕКТНАЯ фраза; править надо `:62-63`. Тот
  самый класс, который кампания ловит четырнадцать волн подряд, — в моём тексте.
- **Всегда `touch` файла теста перед доверием контрфакту** (item #1073): общий
  target-каталог + worktree дают протухший `CARGO_MANIFEST_DIR`.
- **Вердикт `npm run check` читать из тела лога**, никогда из кода выхода.
- **Landing SHA читать с remote** (`git fetch && git rev-parse origin/main`),
  не из локального HEAD.
- **Утверждения о составе переизмерять, а не переформулировать** — четвёртое
  поколение этого дефекта заведено как #1185.
- **Фоновый агент может умереть на обрыве связи, потеряв весь результат.**
  Просить его писать промежуточные выводы по ходу, а не копить отчёт до конца.
