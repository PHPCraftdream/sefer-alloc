**Key lessons learned:**
- **Merge method.** PRs that carry evidence receipts must be merged with a merge commit, and `main` must be brought into the branch with `git merge`, never a rebase. Otherwise the receipts' `source_sha` stops being an ancestor and the registry check turns RED (`source-scope-git`).
- **Source scope.** A refreshed strong row needs an entry in `docs/evidence/source_scope.csv`.
- **Inventory counts.** README/ARCHITECTURE counts drift every time any PR lands, so each PR must merge `main` and recount right before it is merged.
- **Recipe stdout regexes.** cargo's "Running" lines contain ANSI codes. Mutant binaries can crash without printing their panic, so match "process didn't exit successfully: .*<test>".
- **`HeapLease::drop`** aborts if the thread is panicking, so an assertion with a live lease shows up as SIGABRT.
