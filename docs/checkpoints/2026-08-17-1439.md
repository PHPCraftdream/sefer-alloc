- **Verification must cross-compile, not just native-`cargo check`** — a Windows-only check silently skips all `cfg(unix)`/`cfg(miri)` content entirely; this was caught only because CLAUDE.md's own header comment in the original `lib.rs` already documented the 3-platform verification recipe, prompting a deliberate `--target x86_64-unknown-linux-gnu` + `--cfg miri` re-check that then found real missing imports.
