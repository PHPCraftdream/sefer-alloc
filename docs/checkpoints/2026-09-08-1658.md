- Split `commit` into `virtual_size` + `commit_charge`, each `Option`, absent
  where the OS genuinely does not provide it. Kept a documented
  `charged_or_reserved_bytes()` compatibility accessor so 45 call sites across
  37 files keep producing byte-identical numbers; its rustdoc states outright
  that the reading is platform-dependent.

  measurement-output decision, not a mechanical one; no script parses it

  schedule but not the coupling, since the counters are process-wide.

  instead of closing them on a plausible story.

  per-agent CPU/memory quota (the user set it so other agents keep their
