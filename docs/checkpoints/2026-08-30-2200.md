- **P1-1** (verified by REAL REPRODUCTION, not just reading the report): wrote a standalone crate, confirmed `push(&a,1); push(&a,0); pop(&b); pop(&b);` with TWO DIFFERENT `ArrayLinks` instances `a`/`b` makes `pop(&b)` return `Some(0)` FOREVER — a deterministic, 100%-safe-code, no-race, no-unsafe infinite double-issue of one index. Root cause: `push`/`pop` are independently generic over `&L` per call; nothing binds the head to the backing that was actually written, so a fresh/different backing's `load_next` "coincidentally" returning the live head's own index makes `pop`'s CAS succeed as a no-op (`current -> current`) and repeat.

Asked the user how to fix each blocker via `AskUserQuestion`. **P1-1: user chose the doc-only patch** (explicitly accepting the reviewer's own caveat that this stays exploitable by safe code — no structural redesign, no `unsafe fn`). **P1-2: user asked me to consult `@fm` (Agent tool, subagent_type="fm")** for "a solution that's safe AND fast, no compromises." `@fm`'s independent architecture consult (a genuinely well-reasoned, physically-grounded answer, verified by hand): narrow `INDEX_BITS` from `1..=32` to `1..=16`, guaranteeing a 48-bit tag floor — not an arbitrary round number, but derived from a HARDWARE ceiling: the stack's head is a single shared `AtomicU64`, every successful push (any index, any thread) is an RMW CAS on that ONE cache line, so aggregate push throughput is capped by cache-coherence transfer cost (~10^8-10^9 RMWs/sec, independent of thread count/workload) rather than a guessed workload number. At that ceiling, a 48-bit tag's wrap time is `2^48/2×10^8 ≈ 16 days` minimum, even under the double-adversarial assumption of continuous max-throughput saturation AND one thread parked motionless the entire span. 40 bits (what `INDEX_BITS=24` would give) only reaches ~92 minutes — reachable via a debugger-attached-over-a-weekend scenario. `@fm` explicitly rejected 128-bit-CAS (drops loom's real-type coverage — no `AtomicU128` support — adds unsafe/a dependency, likely turns `pop`'s read-only head load into an RMW without guaranteed `cmpxchg16b`) and hazard-pointers/EBR (categorical mismatch — nothing is dereferenced here, the danger is purely logical index reuse). User approved implementing this recommendation directly.

## Decisions

1. **P1-1 (safe API allows Links-backing mix-up, infinite index double-issue): doc-only patch, user's explicit choice**, over a structural handle-owning redesign or making push/pop `unsafe fn` — user accepted the reviewer's own caveat that the bug stays exploitable by 100% safe code.
2. **P1-2 (wrapping tag not a structural ABA defense at INDEX_BITS=32): narrow the compile-time range to `1..=16`** (48-bit tag floor), per `@fm`'s independently-derived, physically-grounded recommendation (cache-line RMW throughput ceiling, not a guessed workload rate) — user explicitly asked me to consult `@fm` for this and approved the result directly. This is a breaking API change, but the crate has never been published (crates.io 404 for `tagged-index-stack`), so it's the cheapest possible time to make it.
3. **128-bit CAS (wider packed word) explicitly rejected** for the crate's default primitive (drops loom's real-type coverage, adds unsafe/a dependency, likely slows `pop`'s read path) — documented as a considered-and-rejected option, with a note that a genuine future need for >65535 indices would be a separate opt-in type, not a change to this default.
4. **P2-3 (doc(hidden)-pub isn't truly non-callable): wording fix only, no structural change** — restructuring would contradict this repo's own explicit, project-wide CLAUDE.md-sanctioned "doc-hidden test-only forwarder" convention used across multiple crates; only tightening the wording so it doesn't overclaim enforcement it doesn't have.
5. **Continuing the established round-1 cadence for round 2**: one `/rush` task per finding (or small logically-grouped bundle), each personally zero-trust-reviewed (diff read in full, tests/doc/fmt re-run, and for the two P1 blockers, REAL reproductions/arithmetic re-derivation done by hand, not just trusting the rush agent's or the reviewer's claims) before committing.
