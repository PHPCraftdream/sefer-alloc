## Decisions

- **perf-gate: закомментировать оба автоматических триггера, `workflow_dispatch` оставить.** Полностью убрать `on:` нельзя — Actions отвергнет файл. Отвергнут вариант «просто убрать крон»: ручные прогоны остались бы гарантированно красными из-за замороженного baseline.
- **Не чинить самоблокировку perf-gate сейчас.** Добавление `if: always()` ПЕРЕЗАПИСАЛО БЫ замороженный baseline на `42d8d223` — единственную оставшуюся точку отсчёта для нерасследованной регрессии.
- **OH3 запущен тремя агентами, не пятью.** Пять сегодня выбили rate limit. Разбиение по файлам, а не по темам — оба межагентных конфликта OH2 возникли там, где две задачи касались одного файла.
- **Синтетический `granted_huge: true` в тесте оставлен.** Проверено лично: `Drop` не ветвится по флагу, rustdoc объявляет последствие не-UB. Ревьюер согласился, но дал аргумент лучше: несущим должно быть ПЕРЕЧИСЛЕНИЕ читателей флага (четыре, три — ранние выходы, `Drop` не среди них), а не цитата про не-UB, которая молча обесценится при рефакторинге.
- **M2 (#1084) закрыт правкой документации, а не кода.** Расширение предиката перевернуло бы свободный `try_decommit(1, 1)` с `Err` на `Ok` — ослабило бы ровно ту валидацию, которую усиливает M3 в той же волне.

## Мои ошибки в этой сессии — чтобы не повторить

1. **Написал в тело коммита то, чего не проверил** («оба набора получили пропуск») — поймало ревью. Правило: утверждение «все N файлов сделаны так-то» обязано подкрепляться командой, показывающей N совпадений, а не памятью.
2. **Направил stdout и stderr одного агента в один файл** двумя дескрипторами; `TaskStop` убил обёртку, а не процесс crush, тот удержал блокировку и отбил перезапуск. Блокировка лежит в `.crush` **воркtree**, а не главного чекаута.
3. **Первый контрфакт для L8 был невалиден**: python-патч заменил ПЕРВЫЕ вхождения якорей, принадлежащие другому тесту. Целевой тест показывал `ok` в обоих прогонах.
4. **Дважды поверил красному прогону после отката инъекции**, который был воспроизведением устаревшего бинаря. Правило: засчитывать только при видимой строке `Compiling`.
5. **Запустил пять параллельных агентов** и выбил rate limit, потеряв два прогона.
