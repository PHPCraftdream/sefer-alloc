So a real `MAP_HUGETLB` grant on `ubuntu-latest` is now execution-proven, not
reasoned-from-spec.

**#1164 is the most substantive OX2 task and came from checking the reviewer's
premise rather than accepting it.** The @ox review asserted "nothing in the
repository observes the kernel's response to madvise at all". That is true for
plain builds only — under `bench-internals`, `src/os/unix.rs` ~`:1116-1121`
reads `ret` and records `UNIX_MADVISE_ATTEMPTS`/`UNIX_MADVISE_SUCCESSES`, and
the hugetlb job runs with that feature on. So a counter-delta oracle was
cheap, and #1164 built it: two assertions (`attempts` rose → the syscall was
reached; `successes` rose → the kernel returned 0), preceded by a hard
`is_huge()` assert so it cannot measure the ordinary-page fallback.

**Uncertain / unverified.** #1164's oracle has never executed against a real
hugetlb pool — only a scratch counterfactual outside the repo proving the
assertion is not tautological. Its first real run is the next CI cycle.

## Decisions

- **Отказ `madvise` внутри `aligned-vmem-hugetlb-real` = красный билд.** Принято
  мной явно как owner decision и записано в тело коммита `cecdeec`, а не
  оставлено умолчанием. Основание: пул сконфигурирован этим же джобом, диапазон
  eligible по построению, реальный грант уже жёстко утверждён — «ОС может
  законно отказать» из контракта крейта эту ситуацию не описывает. Агенту было
  разрешено не согласиться; он проверил независимо и согласился.
- **Вариант (i) + затем (ii), а не (i) вместо (ii).** #1160 понизил заявление
  до правдивого; #1164 затем сделал сильное заявление истинным. Отвергнут
  zero-readback тест (мог падать в условиях, которые контракт терпит) в пользу
  counter-delta assert.
- **Предупреждение, а не падение, при росте счётчика над полом** (#1161).
  Принял довод агента против собственного склонения: жёсткое падение
  обеспечило бы лишь ПОЛОВИНУ связки (скрипт не видит карточку), создавая
  впечатление, что обеспечена вся.
- **Исходные цифры «13 записей / 11 violations» помечены как исторические, а
  не переписаны** (#1163) — `:356` обосновывает решение тем, что было верно на
  момент его принятия; подстановка сегодняшнего числа переписала бы основание.
- **Префикс `fix(perf)` → `build:` на `dad4d7a` до пуша.** Собственный линт
  репозитория провалил коммит; я перепроверил утверждение линта сам и переписал
  префикс, записав факт в тело коммита.
