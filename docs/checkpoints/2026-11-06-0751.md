## Decisions

1. Общие параметры и обучение рантайма вместо per-thread/per-task/per-block идентичности: async-задачи мигрируют между потоками, архитектуру приложения/планировщик не переделываем.
2. Бюджет — outstanding байты подсказанных диапазонов; действует в Always и Auto, 0 = unlimited. Не обещать RSS cap и не использовать cap128 блоков как гарантию 256 МиБ. На неопределённом OS-отказе advice удерживать заранее занятый бюджет до release/доказанного rollback.
3. Обучение только по свежим unhinted controls; hinted residency и повторные cache lives загрязнены. Для v1 нет live sampling чужих mapping, реестра/pinning/фоновых потоков; наблюдение на free при гарантированно живой mapping, задержка обучения длинноживущих блоков признана.
4. Математика: Q31, асимметричное EMA, среднее+anchor, bounded curve (Generous sqrt / Linear / Strict square), без float pow и callbacks. Cautious быстро вниз/медленно вверх, Eager наоборот, Steady сглаженный. Фиксированные параметры — пока кандидаты, не измеренный оптимум.
5. Пользователь разрешил **push и PR** через AskUserQuestion для CI, без local tests/benches. Merge в main, переключение production/default Auto и performance GO не разрешены этим решением. До подтверждённого CI не считать фундамент завершённым.
